**What changed:** `prompts/system.md` only: one added "Single Retry" section (if the first targeted check fails after a source edit, make at most one different second attempt, then submit the best patch). Everything else, including `eval_config.yaml` (4.5 min / 50 tool calls / 50 turns) and sampling, is copied unchanged from `dipin-step-budget-v1`, which is the control.
**Why:** many wrong/incomplete fixes fail the agent's own check once and then either stop or thrash; a single alternate attempt targets recoverable first-try mistakes without blowing the time budget (empty/wrong-fix failures).
